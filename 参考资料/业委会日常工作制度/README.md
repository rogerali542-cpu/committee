# 业委会日常工作制度（参考材料归档）

本目录归档瞿溪新村业主委员会《日常工作制度汇编》的原件与转录，**作为项目开发的参考材料**，尤其供后续「印章管理 / 用印台账」等功能取用。之前这份材料只在会话里出现、没有落进仓库，导致再次会话时找不到；现固化到此，避免再次丢失。

## 文件清单

| 文件 | 说明 |
|------|------|
| `日常工作制度汇编.md` | 全 7 项制度逐字转录（接待日 / 工作记录 / 信息公开 / 印章管理 / 档案管理 / 工作例会 / 财务管理） |
| `印章管理制度.md` | 第四节「印章管理制度」单独抽出 + 结构化要点，供功能建模直接对接 |
| `业委会公章-透明底.png` | 从原件封面提取、去底的红色公章素材（印文「上海市黄浦区瞿溪新村业主委员会」+ 五角星） |
| `业委会公章-白底.png` | 公章原样裁切版（含少量封面黑字穿透），对照备份 |
| `日常工作制度汇编-原件扫描.pdf` | 原件扫描（9 页，2019 年 12 月修订，封面盖公章） |

## 来源

《日常工作制度汇编》，落款「瞿溪新村业主委员会」，「二〇一九年十二月修订」，封面盖「上海市黄浦区瞿溪新村业主委员会」公章。由用户提供的材料压缩包（材料2）中的 `日常工作制度汇编.pdf` 转录、提取而来。

## 使用与敏感性提示

- 这些是本业委会**真实**制度与**正式印章**。小程序演示数据当前走的是虚构小区（见「敏感信息保护」相关整改），因此**引用本材料入库时要区分**：制度文本可作参考/模板，真实小区名、金额额度、公章图等敏感内容是否进入线上功能，需业委会确认。
- 公章图属敏感资产，仅限项目内部/线下用印场景，**勿公开外传**。当前小程序对纪要/公示 PDF 的设计是只留「(盖章)」位、线下加盖；是否线上叠加此章，另行确认。
