# 业委会 App 测试素材（演示用）

覆盖近期改动涉及的场景：**新建会议拍照/上传→OCR判类预填**、**材料OCR喂AI纪要**、
**「上传录音并生成会议纪要」一键流程的四种表决核对分支**、**AI 提炼现场意见**。

生成脚本（可重复生成）：
- 文档图片：`python gen_docs.py`
- 会议录音（离线中文 TTS，16k 单声道 mp3）：`powershell -ExecutionPolicy Bypass -File gen_audio.ps1`

## 一、四个测试会议（录音 ↔ 通知 ↔ 材料 一一对应）

四段录音刻意对应「识别录音并生成会议纪要」后台 `voteCheckFlow` 的四种分支，
上传录音后应分别看到不同的提示/行为：

| 会议 | 录音（会议录音/） | 命中分支 | 上传录音后预期表现 |
|---|---|---|---|
| **A 电梯与监控** | `A_电梯与监控_有表决报票.mp3` | ② AI 识别到票数 | 弹「AI 识别到表决结果」两条（同意7/反对1/弃权1、同意6/反对2/弃权1）→ 确认填写 → 生成 |
| **B 物业费** | `B_物业费_讨论未表决.mp3` | ③ 有表决议题但没报票 | 弹「还有议题没有表决」（仍要生成／先去表决） |
| **C 季度通报** | `C_季度通报_无表决.mp3` | ① 无表决议题 | 不问表决，直接生成纪要 |
| **D 电梯与充电桩** | `D_电梯与充电桩_混合.mp3` | ②+守卫 | 电梯议题识别到票数(同意8/反对0/弃权1)确认填写 → 生成前守卫提示「充电桩」议题还没表决 |

每段录音里都夹了委员发言（王建国、张桂芬、刘美兰、赵德海、孙丽、周涛、吴敏…），
可一并验证 **AI 提炼现场意见 + 未认领标签** 功能。

## 建议的端到端演示顺序
1. 新建会议 → 拍照/上传 `通知A_*` → 看 OCR 判为「通知」并预填会议名称/时间/地点/议题。
2. 给会议逐条挂 `材料_*`（判为「材料」传阅），观察后续 AI 纪要是否引用材料细节。
3. 进入会议 → 录音卡点「上传录音并生成会议纪要」→ 选对应 `X_*.mp3` → 观察四种表决核对分支与最终纪要。
4. 议题弹层里查看 AI 提炼出的「现场发言」意见及「未认领」标签。

> 注意：录音里的票数与人名均为**虚构测试数据**；演示完记得清理测试会议。
