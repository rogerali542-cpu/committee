## 二、腾讯地图 key 申请（lbs.qq.com）

1. 打开 https://lbs.qq.com → 右上角注册/登录（QQ 或微信扫码）；
2. 进入**控制台** → 左侧「应用管理 → 我的应用」→ **创建应用**：
   - 应用名称：`业委会智能履职`（随意，但下面 referer 要用到，记住它）
   - 应用类型：出行/生活服务 随意；
3. 在该应用下 → **添加 Key**：
   - Key 名称：`h5-locpicker`
   - 勾选用途：**WebServiceAPI** + **JavaScriptAPI**；
   - 「启用产品」里若有「微信小程序」不用勾（我们是 H5）；
4. Key 安全设置（创建后点 Key 进入设置）：
   - **授权域名（Referer 白名单）**：加上你的正式域名 + 测试域名，例如：
     `localhost:5173`、`你的内网IP:5173`、`*.trycloudflare.com`（公网预览用）、正式域名；
   - 不设白名单也能用，但 key 被盗刷风险大，建议设。
5. 记下：**KEY**（形如 `XXXBZ-XXXX-XXXX...`）和**应用名称**（referer）。

1. 打开 https://console.amap.com → 注册/登录 → 完成**个人开发者认证**（身份证，秒过）；

## 四、代码接入（腾讯选点组件方案，拿到 key 后我来做）

原理：腾讯提供现成的选点页面 `https://apis.map.qq.com/tools/locpicker`，
iframe 嵌进弹层，用户搜索/拖图选好点后，页面通过 `postMessage` 把
`{ latlng: {lat, lng}, poiaddress, poiname }` 回传给我们。

### 1) 配置（`h5/.env.local`，不入库）

```bash
VITE_TXMAP_KEY=你的腾讯key
VITE_TXMAP_REFERER=业委会智能履职      # = 腾讯控制台里的应用名称
```

### 2) 新组件 `h5/src/components/MapPicker.vue`（核心逻辑示意）

```html
<template>
  <div v-if="open" class="mp-mask">
    <div class="mp-sheet">
      <div class="mp-head"><span>从地图选择地点</span><span class="mp-close" @click="close">×</span></div>
      <iframe :src="pickerUrl" class="mp-frame" frameborder="0"></iframe>
    </div>
  </div>
</template>
<script setup>
const pickerUrl = 'https://apis.map.qq.com/tools/locpicker?search=1&type=1'
  + '&key=' + import.meta.env.VITE_TXMAP_KEY
  + '&referer=' + encodeURIComponent(import.meta.env.VITE_TXMAP_REFERER)

window.addEventListener('message', (ev) => {
  const d = ev.data
  if (!d || d.module !== 'locationPicker') return   // 组件回传标记
  emit('picked', {
    address: d.poiaddress,        // 如"上海市静安区××路×号"
    name: d.poiname,              // 如"党群服务中心"
    lat: d.latlng.lat, lng: d.latlng.lng
  })
}, false)
</script>
```

### 3) 接到发起会议（`Committee.vue` 的 `pickLocationOnMap()`）

演示桩整段替换为：打开 MapPicker → `@picked` 回调里
`createForm.location = name + '（' + address + '）'`，经纬度暂存
`createForm.locationLat/Lng`（后端 meeting 表加两列，顺手让详情页导航用精确坐标：
`uri.amap.com/marker?position=lng,lat` 比关键字搜索准）。

### 4) 验证清单

- [ ] 本地 5173 打开发起会议 → 从地图选点 → 出真地图、能搜索、能定位；
- [ ] 选点确认后地址回填到地点输入框；

## 五、高德 JS API 方案（备用，要嵌入式地图/自定义样式时用）

```bash
# .env.local
VITE_AMAP_KEY=你的高德key
VITE_AMAP_JSCODE=你的高德安全密钥
```

```js
// 安全密钥必须在加载 JS API 前设置（官方要求）
window._AMapSecurityConfig = { securityJsCode: import.meta.env.VITE_AMAP_JSCODE }
// 动态加载 https://webapi.amap.com/maps?v=2.0&key=KEY
// 建图：new AMap.Map(el, { zoom: 16, center: [lng, lat] })
// 选点：地图中心固定一个 marker，监听 'moveend'，用 AMap.Geocoder.getAddress(center)
//       逆地理拿地址；再配 AMap.PlaceSearch 做关键字搜索。
```

⚠ 生产环境安全密钥不建议明文（可用 nginx 代理 `_AMapService` 方案，见高德文档
「JS API 安全密钥使用」）；演示期明文可接受。
